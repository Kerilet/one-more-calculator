# One More Calculator

This project was made as a submission to the following challenge proposed by Professor Gustavo Ferreira Palma:

### Browser adaptation for the calculator previously developed in Android classes

Using the following technologies:
HTML
CSS
JavaScript
Vue.js (optional)    
    
### Objective

Develop a calculator using HTML, CSS and JavaScript, with the option of using the Vue.js framework, applying the concepts of interface construction, event manipulation and dynamic element updating.

### Activity description
Create a Web application that simulates a conventional calculator, presenting an interactive graphic interface and allowing the user to make basic math operations.
The app shall have an organized interface, with numeric buttons, operator buttons and a visor to show the inputted values as well as the operations' results.

### Mandatory Requisites
       
- The interface shall be created using HTML and CSS.
- Implement the calculator logic using JavaScript, with or without Vue.js
- All numeric buttons from 0 to 9 shall be available.
- All four basic math operations, those being addition, subtraction, multiplication and division, shall be implemented.
- A button to calculate and show the operation result shall be implemented.
- A button to clear the inputted values shall be implemented.
- Decimal numbers should be usable.
- The visor used to show the result shall be dynamically updated according to user interaction.
- Invalid situations, such as division by zero, shall be managed.
- The interface shall be responsive, being usable in both computers and mobile devices.

### Additional Requisites (optional)
- Implement a function to clear the last digit.
- Allow keyboard usage of the calculator.
- Implement additional operations, such as percentage and square root.
- Add light/dark theme support.
- Implement a history funciton that saves previous operations.

### Orientations

The activity can be developed using either pure JavaScript or Vue,js, being up to the student to use either one.

All operation logic shall be implemented by the student themselves, avoiding the use of functions that directly compute math expressions served as text, such as `eval()`

### Delivery
All the necessary files to run the Web application, including HTML, CSS and JavaScript ones, shall be delivered.

The application shall work directly on a browser, without the need to install additional tools

The reasoning behind the logical technology choice (Vue.js or Pure JavaScript) shall be specified on the either the project or the repository's README on GitHub.

### Reasoning behind my choice of Vue.js
My main reason for choosing Vue.js over pure JS is taking the opportunity of learning new ways to code, using the activity's familiarity to my advantage to make my learning quicker and easier. Another motive worth noting is my knowledge of other JS related frameworks, in this case NEXT.js (which is technically a framework of React.js that, in and of itself, is actually a JS library), which sparked the curiosity and desire to work with somewhat similar technologies.
